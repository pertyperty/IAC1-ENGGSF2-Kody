# Replaceable Kody artwork

`kody-mark.svg` is the current original Kody placeholder logo. Its single shared
path is configured in `config/branding.php` and rendered by `layouts.brand` plus
the rail/favicon. Replace it with approved branding in this public directory and
change that configuration; keep meaningful dimensions and accessible text.

`navigation.svg` is original Kody placeholder line artwork for the collapsed
role-filtered navigation rail. Symbol IDs are the stable icon API. It uses the
shared theme's current color; controls still have accessible text/keyboard focus.

Existing garden/explorer SVGs are original placeholder game artwork. No Coddy,
Duolingo, Candy Crush, MIT or Harvard logos/assets have been copied. Existing
asset/font provenance remains in docs/navigation-and-visual-polish.md and the
pinned font directory's README.

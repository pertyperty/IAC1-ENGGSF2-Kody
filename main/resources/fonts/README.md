# Pinned interface fonts

Unmodified normal Latin WOFF2 files acquired through Bunny using the existing
Laravel Vite font integration on 2026-10-07. Local explicit weight mappings are in
`vite.config.js`; rebuilding needs no font-provider network calls. Font display
uses the plugin's `swap` default and only body 400/heading 600 are preloaded.

Space Grotesk: Copyright 2020 The Space Grotesk Project Authors,
[upstream](https://github.com/floriankarsten/space-grotesk).
Instrument Sans: Copyright 2022 The Instrument Sans Project Authors,
[upstream](https://github.com/Instrument/instrument-sans).
Both are SIL OFL 1.1; retain [Space Grotesk's notice](../../public/fonts/OFL-Space-Grotesk.txt)
and [Instrument Sans's notice](../../public/fonts/OFL-Instrument-Sans.txt) with releases.

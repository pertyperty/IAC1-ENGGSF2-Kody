# Formatting learning content

Module bodies and coding challenge descriptions, rules, input and output can use Markdown. Use headings to break up explanations, lists for steps, inline code for identifiers, and fenced code blocks for examples. A language name after the opening fence labels the example. Ordinary line breaks are kept.

Author HTML displays as text. Links and images display only their labels, so prose cannot load external resources or embed scripts. Publishing still stores the original text in an immutable revision; formatting happens when a reader or preview opens it.

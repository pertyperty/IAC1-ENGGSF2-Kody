# Learning assessment maintenance

On version 3 quizzes, authors can add a hint to an individual choice. An incorrect answer shows that hint when present, then the question's general retry feedback, then the existing explanation. Correct answers show the explanation. Adding a hint to a legacy question creates a version 3 quiz on save; existing snapshots and answer IDs remain unchanged. Matching menus use the same question-seeded ordering in previews and published views, while grading compares saved pair IDs.

Arcade's text editor accepts both the displayed pseudocode and its older command format. The shared bounded grammar translates supported syntax to canonical commands before applying game and assessment rules. Terminal Quest keeps its existing simulated command syntax. Pseudocode is not general-purpose code and is never executed as such.

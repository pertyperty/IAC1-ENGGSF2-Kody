# Current learning policy summary

Reviewed against implementation and owner amendments on 17 November 2026.
This is a summary, not a new reward policy. Linked decisions and server-side
implementation remain authoritative; superseded milestone wording is historical.

| Activity / concept | Current rule | Authority |
| --- | --- | --- |
| Tower | 80 free floors in independently enterable Beginner, Intermediate and Expert tracks; order enforced inside each. Final-stage confirmed clears save progress and qualify Manila streaks; no extra Tower XP/KB. | [Expansion](tower-skill-expansion.md), `TowerProgression` |
| Continue | Selected Tower track drives the primary action. Starter lessons are optional supporting practice with preserved history/rewards. Track labels are not certification. | [Consolidated flow](consolidated-learner-flow.md) |
| Starter lessons | First server-validated game clear and quiz win each award 20 XP per starter lesson; qualifying saved wins support streaks. No historical backfill. | [Economy](economy-implementation.md), `LearningProgression` |
| Creator lesson assessments | First eligible validated completion grants 40 XP once per module across revisions/course contexts. Qualifying assessment activity supports streaks; replays do not repeat XP. | [Economy](economy-implementation.md), `LearningProgression` |
| Article-only reading | Authorized opening plus explicit Mark as read can grant 40 XP once per module across standalone/course use. No streak, assessment prerequisite or Contributor credit. This supersedes older blanket no-reading-XP wording. | [Studio/media amendment](studios-media-and-integration-readiness.md), `ModuleReading` |
| Coding challenges / weekly | Verified passes use adopted difficulty XP and separately configured weekly awards. Attempts, pinned revisions, provider readiness and capped publication remain server-controlled; live Judge0 is deferred. | [Economy](economy-implementation.md), [Weekly](weekly-challenge-plan.md) |
| XP / rank | XP builds achievement ranks; purchases grant no XP. Rank is separate from role and reviewed qualifications. | `config/economy.php`, `Achievements` |
| KodeBits / finance | Access/ledger currency, not a general Tower-clear reward. Balances, provenance, remedies and history remain protected while live finance activation is deferred. | [Decisions](economy-and-launch-decisions.md), [Deferrals](deferred-features.md) |
| Local preview / guest trials | Step/Replay/Restart and trials do not establish saved achievement, paid access or role eligibility. Authorized explicit completion saves authoritative results. | [Teaching/onboarding](panel-learning-and-onboarding.md) |
| Contributor eligibility | Existing account-age and distinct validated module/challenge thresholds apply. Tower play does not replace required challenge passes while execution is disabled. Local synthetic role fixtures are a separate guarded demonstration exception. | [Applications](contributor-application-plan.md), [Role demo](role-application-demonstration.md) |
| Creator credibility | Username/supplied public details only. Role pills differ from staff-issued qualification checks; documents and review notes stay private. A badge does not certify every claim or lesson. | [Creator credibility](simple-learning-and-creator-credibility.md) |

Reviewed operator, eligibility/geography/retention facts and Terms acceptance remain
public-launch requirements. They are not inferred from this summary or local tests.
See the [release evidence index](release-evidence-index.md).

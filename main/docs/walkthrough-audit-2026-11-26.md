# Full-Role Website Walkthrough & Fixes — 26 November 2026

End-to-end UI/UX, behavior, and terminology walkthrough across guest registration (Learner and Educator paths), learner exploration, Contributor and Instructor applications, Instructor studio workflows, Contributor workflows, Moderator review/moderation queues, and Administrator operations.

## Findings & Fixes by Journey

### 1. Registration & Educator Onboarding (`welcome.blade.php`, `account/register.blade.php`, `RegistrationController.php`)
- **Finding:** Educators had no clear signup entry point from `/welcome` or `/register`, and `/register` still used the legacy auth layout instead of Visual System v2 `account-shell-auth` used by `/login`.
- **Fix:** Added a clear `"Join as an educator"` path (`route('register', ['role' => 'educator'])`) on `/welcome` and `/register`, updated `RegistrationController::create` to pass `$forEducator`, displayed a 3-step educator onboarding guide on `/register` while preserving the exact 4-field verified signup contract, and upgraded `/register` to `account-shell-auth`.

### 2. Learner Exploration & Role Applications (`account/contributor-application.blade.php`, `account/instructor-application.blade.php`, `account/profile.blade.php`)
- **Finding:** Contributor eligibility milestones appeared as a single dense text line without progress bars or quick links; Instructor application used mismatched terminology (`Become a learning creator` / `TURN KNOWLEDGE INTO ADVENTURES`), lacked a clear summary of unlocked Instructor tools, and rendered application history as plain `<p>` rows; role-upgrade actions on Profile were split across different sections.
- **Fix:** Built a 3-card `.milestone-grid` eligibility checklist with `<progress>` bars, met/remaining pills, and catalog links on Contributor application; aligned Instructor application to `INSTRUCTOR APPLICATION` / `Apply to become an Instructor` with a `"What Instructors can do"` strip and structured history cards (retaining exact test button label `Apply to become a creator`); grouped role-application links together on Profile.

### 3. Instructor & Contributor Workspaces (`learning/hub.blade.php`, `content/studio.blade.php`, `content/courses.blade.php`, `content/course-preview.blade.php`, `challenges/studio.blade.php`, `transactions/earnings.blade.php`)
- **Finding:** Instructor/Contributor quick actions were buried below dashboard panels; `.creator-play-link` was unframed; Module studio labeled modules as `lessons` in the count pill and had a grammatical typo (`Create module or start...`); Course studio lacked `.studio-heading`, wayfinding pills, row action cues, and `<x-empty-state>`; Course preview used stale `adventure` copy (`Course adventure preview` / `Try the saved adventure.`); Challenge studio labeled Published and Archived challenges as `Open draft`; Earnings used `PHP500` without a space and a vague heading (`Keep your work rewarding.`).
- **Fix:** Added a top Creator Quick Actions bar on Dashboard; framed `.creator-play-link`; aligned Module & Course studios with shared `.studio-heading`, wayfinding (including Public profile & Earnings), `module`/`modules` wording, and `<x-empty-state>`; updated Course preview to `Course module preview` / `Preview saved module`; fixed Challenge studio row labels by status (`Open challenge` / `View archived` / `Open draft`); standardized `PHP 500` and `Your earnings and refunds`.

### 4. Moderator & Administrator Operations (`layouts/review-nav.blade.php`, `layouts/staff-tools.blade.php`, `challenges/reviews.blade.php`, `challenges/review.blade.php`, `content/course-reviews.blade.php`, `account/contributor-reviews.blade.php`, `content/moderation-index.blade.php`, `weekly/studio.blade.php`, `tower/studio.blade.php`, `transactions/finance.blade.php`, `account/system-reports.blade.php`)
- **Finding:** Challenge reviews had a stale slogan heading (`Help a good quest find its learners.`) and duplicate `Adventure reviews · Course reviews` links below `review-nav`; Course reviews duplicated the `Module reviews` link; Challenge review used `Every check` / `Check N` instead of `Test cases` / `Test case N`; Contributor reviews used stale `Review future quest creators`; Moderation & Weekly studio had vague slogan headings (`Keep learning safe.`, `A fresh challenge for every week.`) and Weekly studio linked back to `Review studio`; `review-nav` omitted Instructor and Contributor application queues; `staff-tools` omitted the unified `Review inbox` and called Help `Help workshop`; Tower studio track filter lacked `aria-current="page"`; Finance had `PHP12,000` without a space and lacked `ADMINISTRATOR WORKSPACE` overlines matching Site management.
- **Fix:** Standardized all headings, overlines, and queue navigation across Moderator & Administrator views; added Instructor/Contributor queues to `review-nav` and `Review inbox` to `staff-tools`; added active `aria-current="page"` state on Tower studio track filters; formatted `PHP 12,000`; added `.operation-row` wrapping styles for Site management.
